# fontcreator233 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `fontcreator`, a deterministic offline Go CLI that turns agent-authored recipes into multilingual TTF/WOFF fonts, platform integration packages, and a local offline HTML specimen.

**Architecture:** A parametric glyph engine generates Latin/Greek/Cyrillic outlines; an embedded static OFL base font supplies CJK/kana/Hangul/symbols. A hand-written TTF/WOFF encoder compiles the merged glyph set. Bubble Tea drives progress, a bounded worker pool parallelizes glyph work, and a versioned workspace state makes builds repeatable and cleanup safe. CLI, MCP, and an agent skill expose the same contract.

**Tech Stack:** Go 1.27, `golang.org/x/image/font/sfnt`, `golang.org/x/text/unicode/norm`, `golang.org/x/term`, `gopkg.in/yaml.v3`, Bubble Tea/Bubbles/Lip Gloss, embedded Geist WOFF2 and TanStack Virtual (MIT), local vanilla JS/CSS.

**Spec:** `docs/superpowers/specs/2026-11-17-fontcreator233-design.md`

## Global Constraints

- Go 1.27; `CGO_ENABLED=0`; Windows/macOS/Linux.
- `unitsPerEm = 1000` for every input, generated font, and split font.
- Runtime has zero network requests; base fonts and web assets are embedded.
- Generated outputs are never committed: `dist/`, `out/`, `work/`, `build/`, `tmp/`, `.fontcreator233/`, `*.bundle.zip`, generated TTF/WOFF/HTML/glyph JS, local Unity/Playwright artifacts.
- `.gitignore` keeps `assets/base/*.ttf`, `assets/base/*.txt`, and `internal/specimen/webassets/**` tracked.
- TUI writes to stderr; `--json` writes only the JSON envelope to stdout.
- Deterministic within one fontcreator233 version, OS/arch, and Go version: fixed `head` timestamps (`SOURCE_DATE_EPOCH` or 2026-01-01T00:00:00Z), seed-only randomness, sorted map iteration.
- `--jobs 1` and `--jobs 8` must produce byte-identical fonts on the same platform; cross-platform byte equality is not promised.
- Any output using embedded base outlines is OFL-1.1; recipe cannot override that.
- Font family names are rejected if they start with `Noto`.
- Unity is generated-only: no Unity install/test in the build or CI. UE is generated-only; no UE install/test.
- Cleanup deletes only state-tracked files whose SHA-256 still matches; never deletes untracked or modified files without `--force`.

## Review Focus

1. **Malformed input** — recipes with unknown/duplicate/NaN fields, SVG paths with arcs/relative commands/path traversal, corrupt zip bundles: must fail with a field/path-specific error, never panic or write outside the output directory.
2. **Foreign fonts** — TTF/OTF with non-1000 UPM, missing OS/2, composite glyphs, empty cmap, or unsupported CFF: import must report what is missing and either scale or refuse; text must never silently vanish.
3. **Huge coverage on weak machines** — `common`/`full` coverage with `--jobs` high, cancellation mid-build, low memory: must stream/chunk, keep the previous build intact, and release the workspace lock.
4. **Filesystem edge cases** — paths with spaces/Chinese characters, read-only files, existing user files, symlinks, concurrent builds, Windows rename-over-existing: must preserve user data and produce an actionable error.
5. **Offline specimen** — `file://` with no network, missing assets, font load failure, 40k glyphs: must show an error banner instead of a blank page, render only visible rows, and never reference a CDN or ES module.
