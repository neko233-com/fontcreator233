# Platform packages

`--target all` writes a universal font plus web, system, Unity, and Unreal
packages. Everything is generated by the CLI; no Editor is launched.

## Universal

`Font-Regular.ttf` and `.woff`, `Font-Regular.html`, `fontcreator233.manifest.json`,
`Charsets/`, and `OFL.txt` (when the output uses OFL base glyphs).

## Unity TMP

`unity/` is a UPM package:

```text
unity/
├─ package.json
├─ README.md
├─ Editor/FontCreator233TMPImporter.cs
├─ Fonts/*.ttf
├─ Charsets/*.txt
├─ OFL.txt
└─ fontcreator233.manifest.json
```

Install it under `Packages/<package>/` or `Assets/<package>/`, install
TextMeshPro on Unity 2022.3 (Unity 6 includes TMP with uGUI), then use:

- `Tools/Fontcreator233/Create TMP Font Assets` — dynamic SDF assets.
- `Tools/Fontcreator233/Create Static TMP Font Assets` — populate from
  `Charsets/all.txt`, then switch to static.
- `Tools/Fontcreator233/Wire Fallback Chain`
- `Tools/Fontcreator233/Set as Default Font`

Dynamic mode uses multi-atlas. For mobile static atlases, split the font with
`--split-cjk 4096`; the manifest fallback order matches the generated chunks.
The importer logs missing sample glyphs and does not silently claim coverage.

**No Unity test is run.** The package is generated for compatibility with
TMP 3.x and Unity 6; review/import it in your own project.

## Unreal Engine

`unreal/` contains TTF files, `fontcreator233.manifest.json`, and
`Scripts/fontcreator233_import.py`.

Run the script inside the Unreal Editor Python environment. It imports Font
assets into `/Game/Fonts/<Family>/`. `CompositeFont` creation is attempted only
when the installed UE Python API exposes it; otherwise the script prints the
default/sub-font ranges for manual setup. Set the font cache type appropriate
for your project and cook the font assets.

**No Unreal test is run.**

## Web

`web/font.css` uses local font files:

```css
@font-face {
  font-family: "Aurora Grotesk";
  src: url("./AuroraGrotesk-Regular.woff") format("woff"),
       url("./AuroraGrotesk-Regular.ttf") format("truetype");
  font-display: swap;
}
```

Split fonts are emitted with `unicode-range` on each `@font-face`, so the
browser selects the right file automatically. WOFF2 is not generated; run
`woff2_compress` externally if needed and update the CSS.

## System

`system/` contains a TTF and `INSTALL.md` for Windows, macOS, and Linux. The
font has standard name, cmap, OS/2, and metrics tables and can be installed
directly.

## Licenses

Outputs using the embedded Noto-derived bases are OFL-1.1. The generator writes
`OFL.txt` and records the license in the font name table and manifest. Imported
fonts without a known OFL license are marked `UNLICENSED`; do not redistribute
them without permission.
